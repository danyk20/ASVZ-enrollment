What this command does
  1. Installs uv if missing (the small tool that runs the app).
  2. Downloads the app to your home folder.
  3. Asks for your SWITCH edu-ID login (or skip and add it later).
  4. Optionally sets up email.
  5. Tests the login.
  6. Schedules the weekly run.

Privacy & trust

Your SWITCH edu-ID login is the key to your university account. Here is exactly where it goes, and how you can check it yourself.

Your login never leaves your computer

It is saved in one file, .env, in the app's folder on your own computer. The app sends it only to the official SWITCH edu-ID login, exactly like your browser does. The developer has no copy and no way to get one.

No accounts, no cookies, no personal data

This page counts anonymous usage with GoatCounter: visits, which classes are looked up, which system is chosen and clicks on Copy. No cookies, no IP addresses, nothing about you. The app on your computer talks only to ASVZ and SWITCH edu-ID, plus Brevo with your own key if you turn on the email. It reports nothing back.

Open source: check it yourself

Every line of this website, the setup command and the app is public on GitHub. Anyone can read it, and you can read the setup script before you run it.

Before you start

  • Your computer must be on and awake at the start time.
  • Works with SWITCH edu-ID logins without a code from an app or SMS.
  • If you can't attend, cancel in time: ASVZ blocks you for 8 days after the third no-show.

FAQ

Is this official?

No. It's an independent open-source tool and isn't affiliated with ASVZ.

Where is my password stored?

Only in a file called .env in the app's folder on your computer. It is sent only to the SWITCH edu-ID login.

Can the developer see my password?

No. It is typed on your computer and stays there; nothing is ever sent to the developer. The website only counts anonymous visits and which classes are looked up, and never sees your login. Because the code is public, anyone can check that, line by line, on GitHub.

How can I be sure the code does what it says?

All of it is open source. Read the setup script before you run it, or the app's code in src/asvz_enroll. The login code is in login.py; you will see it only contacts ASVZ and SWITCH edu-ID.

What if my computer is asleep?

Nothing happens that week. Keep it plugged in and awake at the start time.

How do I stop it?

Follow the steps for your system in “Stop or change the weekly enrolment” in the setup guide ↗

The semester is over — now what?

Paste the link of the new class and run the new command. It replaces nothing else.

Can I add a second class?

Yes. Paste the second link and run its command too.
